# BUSINESS_CONTENT_PROTECTION_STANDARD

- 정책 버전/수준: 2026-08-31 / B
- 공개 경계: 안내·권리 확인 로직과 검색 가능한 설명은 공개. 보험·진료 선택은 기기 로컬에만 저장하고 서버로 보내지 않는다.
- 기술 통제: 후기 API origin 제한, 본문 크기 제한, 민감정보 차단, 요청 제한, 중복 해시, 90일 자동 삭제를 유지한다.
- 추적 한계: 서버는 후기 영수증과 최소 기록만 보유하며 앱 콘텐츠 열람자를 사용자별로 추적하지 않는다. 따라서 강한 A 문구를 사용하지 않는다.
- 사고 증거: UTC 시각, 후기 영수증, 종류, 화면 경로, 중복 해시, 배포 버전만 보존한다. IP는 요청 제한에 일시 사용하지만 DB에 저장하지 않고, 보험번호·진료내용·연락처·기기지문을 새로 수집하지 않는다.
- 대응: 악성 요청 제한 → 관련 영수증·배포본 보존 → 운영자 검토 → 필요 시 호스팅 제공자·법률대리인·수사기관과 협력한다.
- AI 제공자: 현재 런타임 생성형 AI 호출 없음. 도입 전 건강·보험 정보 전송 금지, 학습 사용, 보존·삭제, 지역처리, 하위처리자, 사람 검토 절차를 승인해야 한다.
